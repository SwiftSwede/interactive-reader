## How to use in a later slice

1. Open this folder. Do not re-search Mobbin first; the JPEGs are the source of truth in-repo.
2. Cite the Mobbin URL in the slice brief or DESIGN.md only for the live screen.
3. Check `00-BRIEF.md` before copying a row: no gamification, no infinite catalog, student UI stays one column.
4. Character-band overflow (fade + 44px chevron) already took the chip-row cue from these homes.
